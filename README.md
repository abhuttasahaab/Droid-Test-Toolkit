Welcome to Droid Test Toolkit! 📱🔋 Your ultimate centralized workstation filled with optimized FOSS and Premium Android diagnostics APKs to benchmark battery health, audit display components, and troubleshoot any mobile hardware and software. ⚡⚙️

Droid Test Toolkit is a comprehensive, curated collection of Android APK utilities designed specifically for mobile hardware diagnostics, software validation, and system benchmarking. 

Whether you are a hardware technician, an Android developer, or a privacy enthusiast, this toolkit offers a centralized suite of both **Free and Open-Source Software (FOSS)** and **Premium Unlocked** utility applications to thoroughly evaluate any Android device.

---

## 🛠️ Diagnostics & Features Covered

This toolkit contains optimized tools to analyze every major layer of an Android system:

*   **🔋 Battery Health:** Measure real-time current draw, log capacity degradation, view charge cycles, and benchmark thermal performance under load.
*   **📱 Display & Touch:** Screen calibration tools, dead-pixel identifiers, multitouch tracking, and high-refresh-rate verification (60Hz / 90Hz / 120Hz / 144Hz).
*   **⚙️ Hardware Diagnostics:** Sensor polling (Gyroscope, Accelerometer, Proximity, Magnetometer), speaker/microphone frequency tests, and storage read/write performance.
*   **💻 Software & OS Architecture:** Deep system detail viewers, partition mapping, API level verification, and package management utilities.

## 📦 CPU Architecture & Package Guide

To maximize efficiency and reduce system overhead, the packages in this repository are optimised for arm64-v8a CPU architecture with the APK interface language EN-Only, and categorized by their target Instruction Set Architecture (ISA):

*   **`arm64-v8a` Optimized:** The majority of the applications are natively compiled for modern 64-bit environments. These files are explicitly marked with the suffix `arm64-v8a` right before the extension (e.g., `APKName-arm64-v8a.apk`).
*   **Universal Packages:** APK binaries contain multi-architecture fat binaries that run seamlessly across `armeabi-v7a`, `arm64-v8a`, `x86`, and `x86_64` targets.

## 🚀 How to Install and Use

1. **Identify Architecture:** Ensure your target device is running a 64-bit operating system to take advantage of the `arm64-v8a` builds.
2. **Download:** Navigate to the Releases page and grab the diagnostic tools required for your testing criteria.
3. **Enable Sideloading:** Enable *Install Unknown Apps* or *Unknown Sources* for your browser or file manager from your Android system settings.
4. **Install via ADB or UI:**

**Run Diagnostics:** Open the installed app and grant the necessary permissions (e.g., Modify System Settings, Usage Access) to access low-level hardware metrics.
